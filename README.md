# MakeUrWiki - Community Wiki with Proposals & GitHub Storage

A fully functional wiki where anyone can propose edits, and admins approve/reject changes. All data stored in GitHub, works on GitHub Pages. Features dark/light mode, invite tokens, and a Fandom-like interface.

## Features

- **Public viewing** – anyone can read
- **Invite-only editing** – only users with a valid invite link (or admin) can edit
- **Proposal system** – each edit is saved as a proposal with author and timestamp
- **Admin moderation** – approve or reject proposals via a simple panel
- **GitHub storage** – wiki content and proposals stored as JSON files in your repo
- **Auto-save** – proposals created every 5 seconds while editing
- **Export/Import** – backup and restore wiki content
- **Dark/Light mode** – toggle theme, persists in localStorage
- **Responsive design** – works on all devices
- **No backend** – pure frontend using GitHub API

## Setup

1. **Create a GitHub repository** (public).
2. **Upload these files**: `index.html`, `styles.css`, `app.js`, `README.md`.
3. **Enable GitHub Pages** (Settings → Pages → main branch).
4. **Generate a GitHub personal access token** (classic) with `repo` scope.
5. **Open your wiki**, go to Settings, paste the token and save.
6. **Login as admin** (default password: `admin`).
7. **Generate an invite link** in Settings → Invite Editors. Share it with anyone who should be able to edit.
8. **Start editing** – any user with the invite link can click Edit, make changes, and proposals are created.
9. **Admin approves proposals** via "Review Proposals" button.

## How it works

- All data is stored in `/data/wiki.json` (official content) and `/data/proposals.json` (pending proposals) in your repository.
- When a user with a valid invite token edits, a proposal is saved to GitHub (or local backup if offline).
- Admin can preview, approve (replaces wiki.json) or reject (removes from proposals.json).
- Export/Import allow full backup/restore.

## Invite tokens

- Tokens are generated by the admin and stored in localStorage.
- The invite link looks like `https://your-wiki.com/?token=random123`.
- Anyone with that link can edit (create proposals). Tokens can be regenerated at any time.

## Dark/Light mode

- Click the sun/moon icon in the header to switch themes. Your preference is saved.

## Customization

- Change default admin password in `app.js` (DEFAULT_ADMIN_PASSWORD).
- Modify initial content in `DEFAULT_CONTENT`.
- Style variables in `styles.css` (both light and dark themes).

## Troubleshooting

- **"Edit button not showing"** – you need a valid invite token in the URL or be logged in as admin.
- **"Failed to save proposal"** – check GitHub token and repo owner/name.
- **Admin login not working** – default password is "admin" (case-sensitive).
- **Proposals not showing** – ensure GitHub token has repo scope and API rate limits.
